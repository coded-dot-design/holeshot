# Clean-up pass, 2026-11-20 (0.11.0)

A pass over HOLESHOT for dead and duplicated code after about 40 rounds of fast iteration. Nothing
in it changes gameplay, tuning, art or copy. The rule for the pass: nothing is deleted as "dead"
without proof, and the proof is written here next to what was removed.

Base: `migrate/fizlet-org` at `f36b1af`. Sizes are gzip bytes of the committed builds (`npm run check`).

## How "dead" was established

Tools were run from outside the repo (nothing was added to `package.json`).

1. **The compiler**: `tsc --noEmit --noUnusedLocals --noUnusedParameters`.
2. **The import graph**: `knip` with `src/index.ts`, `tests/*.mjs`, `scripts/*.mjs` and the site as
   entries. It reported no unused files and 237 "unused exports"; almost all are constants that are
   used inside their own file and merely carry an `export` nothing needs. Those never reached the
   bundle (esbuild drops them) and were left alone. An export was removed only when a whole-word
   grep over `src/`, `tests/`, `scripts/`, `site/src/` and `docs/` found no other mention (the tests
   read modules through `await import()` namespaces, which knip cannot see, so the grep is the check
   that counts).
3. **V8 coverage of the browser suite**: every file of `test:browser` (plus `controls.browser.mjs`)
   run against an unminified build with Playwright's `page.coverage`, merged across all pages.
4. **A CSS sampler in the same runs**: every 300 ms, in every page (1440 and 390, light and dark),
   each rule of every sheet in the game's shadow root was tested against the live DOM, and every
   class present on any element was recorded. 444 distinct classes were seen across the suite.
5. **The bundle's own accounting**: esbuild's metafile (bytes per source module in the output).

## Shared instead of copied

- `src/colour.ts` `mix`: the same channel-weighted hex mix was written out in `bike/bodies.ts`,
  `bike/rig.ts` and `garage/look.ts` (identical arithmetic, so identical colours).
- `desert/look.ts` `mix` is now imported by `wheelie/scene.ts`, which carried a copy.
- `model/series.ts` `seedMix` is now imported by `online/match.ts`, which carried a copy.

The two colour mixes stay two functions on purpose: one computes `a·(1−t) + b·t`, the other
`a + (b−a)·t`, and they can round differently by one step. Merging them would be a (tiny) art change.

## Kept on purpose

- **Functions the suites never run but the game can reach.** The coverage report listed 210
  never-run functions (24.9 KB unminified, the engine's own included), none of the game's dead: the gamepad reader, online score rides and
  the lost-connection path in `game.ts`, `online/match.ts`'s `scoreSim` and `jamMap`, the Mashup's
  wild scatter, Free Ride's map respawn, friends' trick callouts. They are untested, not unused.
- **`?touchlog`** (`src/debug/touchlog.ts`, 1,645 B minified): a diagnostic that is off unless the
  page asks for it, documented in the CHANGELOG. It is the one debug switch in the production build.
  Removing it is an owner's call, not a proof.
- **The fixed Wheelie City** (`modes/wheelie/city.ts`, `hoods.ts`, about 950 lines): the bundle
  carries 0 bytes of either (esbuild metafile), only tests import them (seven files, the golden
  runs among them). They are a superseded mode kept alive as the test bed for `cops.ts` and the
  bike. Deleting them means deleting or rewriting those tests, which would weaken the gates.
- **State-slot and event enumerations** with unused members (`AW`, `LS`, `E_FLIP`, `L_FLATS`,
  `L_STORE`): they document a numbering; a gap would mislead.
- **Unused parameters** (`sun(c, W, …)`, the patrol's `chase(…, lx, lz, …)`): removing them changes
  call sites for no bytes.
- **Exports used only inside their own file** (about 200): harmless, not shipped twice, and several
  are read by tests through namespace imports.
- **`tests/controls.browser.mjs`**: outside `test:browser` by a recorded decision (CHANGELOG); it
  fails today on "the HOP bubble out on the ground".
- **About 170 selectors the sampler never matched but whose classes are live** (330 unmatched on the base, less the 161 removed) (hover, focus,
  pressed and error states, rare HUD chips, the kit's and the shop's own sheets). A test not
  reaching a state does not prove the state unreachable; `vendor/shop` and the kit are not ours to
  prune.
- **Fixtures and site assets**: every file under `tests/fixtures/` and `site/public/` is read (the
  backdrop fidelity fixtures and the mode stills by template path).
- A stale selector in a test (`.dh-rwrap` in `tests/garage-actions.browser.mjs`'s width check): it
  matches nothing and changes nothing; left so this pass edits no test.
